# Що потрібно завершити вручну перед здачею

1. Відкрити проєкт у VS Code та виконати `dotnet build` і `dotnet run`.
2. Перевірити додавання, перегляд, завершення завдання та збереження у `tasks.json`.
3. Налаштувати Git: `git config --global user.name "Ваше ім'я"` та `git config --global user.email "ваша пошта"`.
4. Створити порожній репозиторій GitHub, додати `origin`, виконати `git push`.
5. Для кожної feature-гілки створити GitHub Pull Request у `develop`, залишити коментар і виконати merge. Локальний merge сам по собі не створює GitHub Pull Request.
6. Зробити скриншоти реального виконання та вставити їх у звіт.
7. Переконатися, що гілки, коміти, конфлікт і тег справді присутні у вашому репозиторії.

Не зазначайте у звіті, що GitHub Pull Request або перевірка програми виконані, доки не зробите їх і не збережете підтвердження.
